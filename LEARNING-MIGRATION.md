# NextPhase Learning Hub
## Dedicated workspace iteration

The working card order is MainStage, Learning Hub, Preparedness. Learning Hub uses the existing 3D card structure and shared controls. Both swipe directions and compact previous/next buttons navigate adjacent cards. Each card retains its own face, scroll, and open-session controls.

The front directly reuses the learning index and adds access to the existing Teachers & Scholars directory. The reverse reuses the shared local Fellowship ledger and composer. It offers a general learning conversation plus resource-specific discussions, accessible through the compact Discuss control in resource panels. Learning replies use resource keys, separate from weekly-study and preparedness keys in the same local store. Conversation references and drafts survive reloads. No new member accounts or messaging backend are introduced.

Return to resource reattaches the original retained panel so the article scroll, journey step, open reflections, and language-letter selection survive a discussion excursion during the current session. Continue learning resumes that activity from the front. After a reload, the saved resource reference reopens with the progress its original implementation already supports. Exact transient view controls and viewport scroll are session state.

All inherited source content and unavailable-path labels are retained. This iteration adds navigation and context-preserving discussion access. Authenticated learning discussions and cross-device learning state require a separate integration decision. No Firebase rules, production records, or production hosting are changed.

Validation passed with check-learning-workspace.cjs, check-learning.cjs, check-workspaces.cjs, and check-common-ground.cjs on phone-sized and desktop Chromium. The checks include the Ancient Library chapter/volume context fix and saved learning discussions. Browser tests use F: for temporary files. This iteration stays on feature/learning-workspace for local review. Physical iPhone Safari and public publication remain review steps.


Open **Study → Tools → Learning Hub**. The Learning Hub is a grouped entry within Study Tools. The article reader and guided journey use the existing full-size excursion pattern.

## Try it

- Start at **?card=learning**. Open Learning Paths and choose **Who Was Paul?**
- Open a reflection and then the full teaching. Use Back to return to the same step and reflection.
- Complete a step, reload, finish the path, review completed steps, and try restart with and without confirmation.
- Browse Articles, fill a search, open a result, and use Back to recover the search. A direct article link looks like **?card=articles&file=who_was_paul.html**. Add a legacy fragment in the file parameter to open its target.
- Open **?card=language-lab**, or the old card names **?card=alephbet** and **?card=greekalphabet**. Pick Kaf to see its final form, switch to Paleo-Hebrew, and then find Sigma in Greek.
- Open **?card=prezis**. Change categories, pick a title, and try the optional player. Catalog browsing uses bundled records. Playback depends on Prezi and the deck’s sharing settings.
- Open **?card=teachings** for the two readings. Direct links **?card=jesus** and **?card=origins** match the original cards. Try a Jesus section shortcut and use Back after opening a related article or an Origins note.
- Open **?card=quizzes**, select a book and chapter, and reveal an answer. Open the chapter and use Back to return to the same question.
- Open **?card=investigations** and search for “three angels, with God distinguished” to find it inside *Two Powers in Heaven?*. Open **Research backlog** for the topic catalog and roadmap.
- Open **?card=sources** for the reference shelf or **?card=ancient-library** for the Ancient Library. In a known chapter, search for a phrase and select a result to jump to the verse.
- To restart the local preview after a reboot, open PowerShell in this checkout, run the lines below, and visit **http://127.0.0.1:8768/?card=learning**.

      $env:NEXTPHASE_PREVIEW_PORT = '8768'
      node serve-preparedness.cjs

- On the local build, **node check-learning.cjs** checks the corpus and these flows in phone-sized and desktop Chromium. The browser suite includes simulated speech and Prezi responses. Live Prezi playback, device voices, and physical iPhone Safari require separate review.

The 2026 sources use different conventions. For example, the Hillel model lists Sukkot on September 26 at 7 PM. Fall Feasts starts that phase on September 25, and the Sukkot counter uses a September 25 effective date and a 7:30 PM rollover. The views retain their original dates and identify their source. The prototype provides a 2026 reference and uses the device clock for legacy rollover rules. Annual generation, calculated sunset, calendar sync and reminders remain outside this migration.

Run **node collect-homegroups-calendar.cjs** to reproduce the Calendar bundle from the four pinned scripts. The collector repairs the legacy encoding of range dashes in dates and citations.
