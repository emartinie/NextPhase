# NextPhase

An independent HomeGroups design exploration for mobile browsers. The dark grouped rows, floating tab bar and compact popovers take their cues from the GitHub and Codex mobile references.

## Try it

Open `index.html` in a browser. The prototype is plain HTML, CSS and JavaScript and needs no build, package installation or server.

1. Choose **Continue study**. Scroll down and open **Genesis 1:1–3**. Follow its link to John, use the panel back button, then close the panel to resume at the original position.
2. Use **Reading**, **Context**, or the flip button to switch study faces. Navigate between tabs to try the saved scroll positions.
3. Open the floating **Companion** from any tab. Ask about creation or light, open a passage from the panel, and return to the conversation. Responses are scripted for the demo.
4. Use **Quick actions** to make a note, **Search** to find the bundled passages and discussions, or **Listen** to try browser narration from the floating player.

Fellowship displays fictional sample conversations. Notes and saved passages are stored in the current browser when local storage is available. Companion conversation and study positions last for the current visit. Narration requires a browser and device with a usable speech synthesis voice. The application has no Firebase, accounts, analytics, or remote data integrations.

## Publish later

GitHub Pages can serve the repository root directly. Once the prototype is approved for publication, enable branch-based Pages for the chosen branch and `/ (root)` in **Settings → Pages**. Review the resulting Pages URL on a phone.
